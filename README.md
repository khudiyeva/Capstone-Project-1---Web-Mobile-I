# Capstone-Project-1---Web-Mobile-I
Project Purpose
This repository contains a Personal Portfolio Website designed to serve two main goals:

Portfolio: To showcase my academic profile, schedule, education, and professional experience, acting as a professional online presence.
Practice Project: To demonstrate proficiency in fundamental front-end web development technologies.

Key Accomplishments & Features
This project is a multi-page website built from scratch using HTML, custom CSS, and the Bootstrap framework.

Custom Design System: Implemented a unified Royal Blue/STEM theme across all pages using CSS Variables for consistent coloring of text, backgrounds, tables, and lists.
Sticky Navigation: Created a fixed, responsive header/navigation bar that remains visible at the top of the screen on all pages, using Flexbox and responsive positioning.

Responsive Layouts:

The Gallery page uses CSS Grid for a visual, responsive photo album layout (switching from 4 columns to 1 column on mobile).
The Home page uses the Bootstrap Grid System to place the profile picture and bio card side-by-side, demonstrating component and utility class usage.
Form and Table Styling: Applied detailed styling to enhance the aesthetics and readability of data tables (Education, Schedule) and the Contact Form.

What I Learned
Building this website provided hands-on experience and reinforced several core web development concepts:

CSS Architecture: Effectively managing complexity using CSS Variables and ensuring media queries correctly handle responsiveness across various breakpoints.
Integration with Frameworks: Successfully incorporating the Bootstrap CDN and overriding its default styles with custom CSS while leveraging its powerful grid and components (like the Card and Buttons).

Fixed Positioning & Centering: Mastering the use of position: fixed for the header and using complex margin/width calculations (90% width, left: 5%) to correctly center fixed elements.
CSS Selectors: Utilizing pseudo-classes (:hover, :active) and pseudo-elements (::before for custom list markers) to create dynamic and decorative effects.
